ssh4ai — Help & Shortcuts

CONNECTING

Double-click any host to open a terminal tab. Multiple concurrent sessions can be open simultaneously.

KEYBOARD SHORTCUTS

Ctrl+Tab : Switch between open tabs
Ctrl+Shift+W : Close active tab
Ctrl+B : Toggle Hosts sidebar
Ctrl+J : Toggle DevOps secondary dock
F11 : Toggle Zen fullscreen mode
Ctrl+V (or Shift+Insert / Ctrl+Shift+V) : Paste to terminal — first use may show a one-time browser prompt asking to allow clipboard access; click Allow

QUICK COMMANDS (MACROS)

When LOCKED 🔒, clicking a macro pill executes it directly into the active session. When UNLOCKED 🔓, clicking opens the editor.

SCRATCHPAD

Use the 5 persistent scratchpad buckets (5-column, 1+2 stacked and single merged layouts). Redaction of sensitive data is handled by Presidio (see the Presidio link in the links dock).
